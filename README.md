# Book Bank

A premium digital library website built with React, TypeScript and Vite.

## Features

- 100+ books
- Search
- Genre filters
- Year filters
- Rating filters
- Language filters
- Sorting
- Grid/list view
- Book details
- My Shelf
- Collections
- Browser reader
- PDF download
- Responsive design
- Mobile navigation
- LocalStorage shelf
- Vercel-ready

## Installation

Install Node.js.

Then run:

npm install

Start development server:

npm run dev

Build production version:

npm run build

Preview production build:

npm run preview

## GitHub

Create a repository and upload the project.

## Vercel

Import the GitHub repository into Vercel.

Vercel should automatically detect Vite.

Build command:

npm run build

Output directory:

dist

## Important

The included PDF system generates valid digital editions using jsPDF.

For production distribution, only provide PDFs that are public domain,
properly licensed, or otherwise legally available.
